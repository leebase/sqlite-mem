# sqlite-mem

sqlite-mem is a proposed tiny, safe, local-first persistent-memory primitive
for AI execution harnesses. A transient executable will save and retrieve
AI-selected memory from a user-owned local SQLite file without requiring a
server, daemon, cloud provider, installer, or user-configured LLM.

The project is pre-implementation. `product-definition.md` is the current
product authority. Research and architecture narrowing come next; no language,
embedding implementation, vector mechanism, schema, protocol syntax, or
packaging design has been selected.

Start with `AGENTS.md`, then follow its AgentFlow reading order.
