# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith, and keep
disagreements about code, not people. Harassment and personal attacks
are not tolerated.

Reports: open a private message to the maintainer via GitHub, or use the
contact options on the maintainer's profile. Reports are handled
confidentially.
